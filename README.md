# Swing Radar

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ygopop1010-netizen/JS-stock-screening)

`render.yaml`에 무료 체험용 웹 서비스 설정을 준비했습니다. 버튼에서 Render 로그인과 GitHub 저장소 연결 후 설정을 확인해 배포할 수 있습니다. 자동 재배포는 꺼져 있습니다. 이 앱에는 로그인과 기기 간 동기화가 없으므로 개인용 체험 단계에 해당합니다. 데이터 제공자의 접근 제한은 배포 환경에서 별도로 확인해야 합니다.

한국·미국 대표 종목을 스크리닝하고 중단기 스윙 계획을 만드는 로컬 웹 앱입니다. Python 3.10+ 표준 라이브러리만 사용하며 별도 패키지 설치나 API 키가 필요 없습니다.

```sh
cd /workspace/JS-stock-screening
python3 -m unittest discover -s tests -v
node tests/test_rules.js
python3 server.py
```

브라우저에서 서버의 8000 포트에 접속합니다. `PORT`로 포트를 변경할 수 있습니다. 서버는 개발용이며 인터넷에 직접 공개하기 위한 인증 기능은 없습니다.

## 현재 기능

- 한국 5종목·미국 7종목 일봉 조회, 시장별 필터와 브라우저 관심 목록
- 한국·미국·일본·홍콩·중국·독일·영국 지수와 VIX·금리 지수·환율·금·원유 추세
- FRED 미국 CPI 전년동월 변화·실업률·유효 연방기금금리·10년/2년 금리차·실질 GDP 연율화 분기 성장 조회
- 기술 점수: 20/60일 추세 30점, 20일 수익률 20점, RSI 45~70 20점, 상대 거래량 15점, 20일 고가 돌파 15점
- 총서 12문항 체크, 재무·자본효율·밸류·업종·수급·이벤트 수동 검토, 투자 가설·반대 가설·청산 계획 기록
- 지수와 날짜를 맞춘 20일 초과수익·이전 구간 대비 개선 확인; MA120은 120일 확보 시 제공
- 구조 손절·1/2차 청산 직접 입력, 비용·계좌 위험 한도·익스포저·연속 손실 기반 수량
- 계획·거시 관측 기록의 브라우저 저장, 투자일지 JSON 내보내기
- 자동 조회 실패 시 실제 일봉 CSV 분석 (`date,open,high,low,close,volume`, 61개 이상)

## 데이터와 한계

Yahoo Finance chart 엔드포인트의 비조정 OHLC 일봉을 사용합니다. 지연·제공자 차단·액면분할·배당이 지표에 영향을 줄 수 있습니다. 기준일과 통화를 확인해야 합니다. 15분 메모리 캐시를 사용하며 자동 조회 실패를 명시합니다. 자동 공급자 OHLC 범위 오류 행은 제외 건수를 표시하며, 매매 검토 게이트는 이 경우 재확인을 요구합니다. CSV는 잘못된 행이 있으면 입력 전체를 거절합니다. 수집 시각은 실시간 시세 기준일을 뜻하지 않습니다.

RSI는 최근 14개 변화의 단순 평균, ATR은 최근 14개 true range의 단순 평균입니다. Wilder 방식과 다를 수 있습니다. 시장 환경은 조회 가능한 주가지수 중 `종가 > MA20 > MA60` 비율로 산출합니다(60% 이상 상승 우세, 30% 이하 방어적). VIX 25 이상과 원화 약세는 개별 경계 지표이며 매매 점수에 자동 반영하지 않습니다.

이 버전은 총서 기반 의사결정 MVP입니다. 기업 실적·재무·밸류에이션과 한국 등 미국 외 경제지표는 사용자 근거 입력으로 검토하며 자동 연동은 아직 없습니다. 시장 폭·업종 확산·기관/외국인 수급, 전체 시장 종목 탐색, 백테스트·알림·증권사 주문은 아직 구현하지 않았습니다. 신호의 수익성은 검증하지 않았습니다. 종목 분석 결과는 페이지 메모리에만 보관되고 계획·관심 목록은 브라우저에 저장됩니다. 지수 CSV는 `^KS11`, `^KQ11`, `^GSPC` 등 지원 코드로 가져오면 시장 레이더에 들어갑니다.

## 총서 규칙과 앱 기준 구분

기준은 사용자 제공 「중수의 투자총서 Version 2」16쪽입니다. 상세 대응은 [STRATEGY.md](STRATEGY.md)에 기록했습니다. 총서는 수치를 고정하지 않으므로 기술 점수·최소 손익비 2·총 위험 한도 3%·왕복 비용 0.3%·연속 3회 손실 후 50% 축소·시세 7일/근거 30일 재확인은 앱의 변경 가능한 초기 기준입니다. 기술 점수가 높아도 필수 검토가 미완료면 기다림을 표시합니다. 0.6% 손실예산은 총서 예시를 초기값으로 사용합니다. 현재 의사결정은 신규 진입 검토 전용이며 보유·축소·손절 자동 분류는 없습니다.

로컬 CSV 계산·API·수량 규칙 테스트와 Chromium에서 가져오기→계획→미충족 게이트→저장 복원·모바일 화면을 검증했습니다. Yahoo는 최종 재시도에서 12종목·14개 시장 지표 실제 일봉 조회에 성공했습니다. 달러/원은 잘못된 39개 행을 제외했으므로 기간 지표의 해석에 주의해야 합니다. 달러/원은 제공자 OHLC 오류를 진단했으며 오류 행을 제외하고 부족하면 수집 실패를 표시합니다. FRED 연결은 프록시 403으로 미검증입니다. FRED 표시 날짜는 관측 기간이며 발표 시각이 아닙니다. 수정된 최신 통계로 계산하므로 발표 서프라이즈나 시점 정합 백테스트에 바로 쓰면 안 됩니다.

네트워크 정책에 `query1.finance.yahoo.com`, `fred.stlouisfed.org` 허용이 필요합니다. 제공자가 접근을 제한하면 허가된 데이터 공급자 연동이 필요합니다. 대체 예시 데이터를 실시간 데이터처럼 표시하지 않습니다.
